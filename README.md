Se comienza con el juego todo en un archivo index.html

Se divide en 3 archivos:

QWEN_OBJECT_GAME/
├── index.html      (Solo la estructura y los enlaces a CSS/JS)
├── style.css       (Todos los estilos y animaciones)
├── script.js       (Toda la lógica del juego, configuración y eventos)
└── README.md       (Instrucciones del juego, ya creado por GitHub)
